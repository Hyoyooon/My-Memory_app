# My Memory — 하루 조각 모음 어플

하루 동안 수집하는 다양한 정보, 루틴, 생각, 필사, 일기를 **날짜별 · 카테고리별 바인더 탭**으로 정리할 수 있는 모바일 웹앱(PWA)입니다.

---

## 주요 기능

1. **바인더 인덱스 탭 UI + Mobbin 미니멀 디자인 시스템 ([`DESIGN-mobbin.md`](./DESIGN-mobbin.md))**
   - 공유해주신 레퍼런스 사진의 **좌측 세로 인덱스 탭(바인더 구조)** + **상단 Try 체크리스트 & 새싹 성장 위젯** + **조각 리스트 카드** 레이아웃을 그대로 구현했습니다.
   - Mobbin 디자인 토큰(`#141414` Ink, `#ffffff` Canvas, `#f3f3f3` Soft Canvas, `#0066ff` Accent Blue, 그림자 없는 1px 헤어라인 및 알약형 Pill 버튼)을 적용했습니다.
2. **8대 카테고리 & 날짜별 기록**
   - **달력 (`📅`)**: 월간 달력 히트맵(잔디 농도) 및 북마크 표시 점 확인, 특정 날짜 클릭 시 그날 작성한 모든 카테고리의 조각글 타임라인 모아보기
   - **루틴 (`🌿`)** / **해야할 일 (`☑️`)** / **정보 (`📌`)** / **생각 (`💭`)** / **행복 (`🍀`)** / **필사 (`✍️`)** / **일기 (`📖`)**
3. **글 작성 + 사진/이미지 업로드 (`📷`)**
   - 모바일 카메라 촬영, 갤러리 다중 선택, 드래그 앤 드롭, 클립보드(`Ctrl+V`) 이미지 붙여넣기 지원
   - 브라우저 단에서 이미지를 자동 리사이징·압축하여 빠르고 가볍게 저장 및 클라우드 동기화
4. **중요한 글 북마크 (`🔖`) & 통합 검색 (`🔍`)**
   - 각 카드 우측의 북마크 아이콘으로 중요 조각 표시 및 상단 `🔖 북마크` 필터로 한눈에 모아보기
   - 제목, 본문, 출처, `#태그` 실시간 검색 및 `Try / Mirror / Learned / Quote` 서브 태그 필터링
5. **실시간 클라우드 DB 동기화 (Supabase) + 오프라인 우선 저장**
   - 설정 없이도 즉시 기기 내부(`LocalStorage`)에 자동 저장되며, 상단 `동기화` 버튼에서 무료 **Supabase URL / Anon Key**를 입력하면 안드로이드 스마트폰과 PC 간 실시간 양방향 동기화가 작동합니다.
   - 언제든 `JSON 백업 내보내기 / 불러오기`로 파일 백업이 가능합니다.

## GitHub 업로드 및 안드로이드 앱 설치 방법

### 1. GitHub Pages로 무료 배포하기
1. 본 폴더의 파일들을 GitHub 저장소(Repository)에 업로드(Push)합니다.
2. GitHub 저장소 상단 **Settings** → 좌측 **Pages** 메뉴로 이동합니다.
3. **Build and deployment**의 Branch를 `main` (폴더는 `/ (root)`)으로 선택하고 **Save**를 누릅니다.
4. 1~2분 후 생성되는 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속합니다.

### 2. 안드로이드 스마트폰에 앱으로 설치하기
- **방법 A (가장 간편 · 권장)**: 안드로이드 Chrome 브라우저로 배포된 GitHub Pages 주소에 접속한 뒤, 우측 상단 메뉴(`⋮`) → **[앱 설치]** 또는 **[홈 화면에 추가]**를 누르면 상단 주소창 없는 네이티브 앱 형태로 설치됩니다.
- **방법 B (APK 파일 생성)**: [PWABuilder (pwabuilder.com)](https://www.pwabuilder.com/)에 GitHub Pages 주소를 입력하고 **Package for stores → Android**를 선택하면 즉시 설치 가능한 `.apk` 파일을 다운로드할 수 있습니다.
