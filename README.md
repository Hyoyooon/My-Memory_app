# My Memory — 하루 조각 모음 어플

하루 동안 수집하는 다양한 정보, 루틴, 생각, 필사, 일기를 **날짜별 · 카테고리별 바인더 탭**으로 정리할 수 있는 모바일 웹앱(PWA)입니다.

---

## 안드로이드 앱 설치 방법
### 안드로이드 스마트폰에 앱으로 설치하기
- **방법 A (가장 간편 · 권장)**: 안드로이드 Chrome 브라우저로 배포된 GitHub Pages 주소에 접속한 뒤, 우측 상단 메뉴(`⋮`) → **[앱 설치]** 또는 **[홈 화면에 추가]**를 누르면 상단 주소창 없는 네이티브 앱 형태로 설치됩니다.
- **방법 B (APK 파일 생성)**: [PWABuilder (pwabuilder.com)](https://www.pwabuilder.com/)에 GitHub Pages 주소를 입력하고 **Package for stores → Android**를 선택하면 즉시 설치 가능한 `.apk` 파일을 다운로드할 수 있습니다.
